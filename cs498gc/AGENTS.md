# AGENTS.md

## Scope

This subtree contains the CS498GC course website. The active course materials are in `fa25/`.

## Authoritative Files

- `fa25/index.html`
- `fa25/*.html`
- `fa25/*.md`
- `fa25/css/*.css`
- `fa25/images/`
- `fa25/files/`

## Workflow

- Treat the course site as a mostly standalone static site with its own CSS and assets.
- Keep links relative to `cs498gc/fa25/` rather than the main-site root.

## Editing Rules

- Do not assume the main-site Bulma styles apply here; this area uses Bootstrap and local CSS.
- When changing navigation or filenames, update every linked course page in `fa25/`.
