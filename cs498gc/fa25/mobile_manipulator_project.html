Command a Husky mobile base equipped with a UR3 manipulator arm and a gripper.

  • Robotis RH-P12-RN gripper
  • Simulated LiDAR and IMU sensors

Mars-themed Gazebo worlds with rock obstacles (see the Mars Gazebo tab).

Installing Mars Terrain Packages

Fall 2025 handout text (not a runnable command)

GazeboMarsRover2 is a ROS 1 (catkin) Mars rover package for Gazebo Classic (package mars_rover_2), last updated May 2021, with a simple Mars terrain world (urdf/MarsTerrain.world). It has no mars_gazebo_terrains package and no download_textures.sh script. Its README links a HiRISE-derived terrain mesh that is hosted outside the repository, so the ROS 2 steps after the clone fail.

# Clone the Mars worlds repository
cd ~/ros2_ws/src
git clone https://github.com/LRCJ/GazeboMarsRover2.git
# (its README links a HiRISE-derived terrain mesh hosted outside the repository)

# Install dependencies
sudo apt-get update
sudo apt-get install ros-${ROS_DISTRO}-gazebo-ros-pkgs
sudo apt-get install ros-${ROS_DISTRO}-gazebo-msgs

# Download Mars texture packs (2GB)
cd mars_gazebo_terrains
./scripts/download_textures.sh

# Build the workspace
cd ~/ros2_ws
colcon build --packages-select mars_gazebo_terrains
source install/setup.bash

Custom World Configuration

Create your own Mars exploration scenario by modifying world files:

Fall 2025 handout text (not a runnable example)

The models this world includes (mars_sky, jezero_crater_terrain, mars_rock_sample) are not in any of the repositories linked from these pages.

<?xml version="1.0"?> <sdf version="1.6"> <world name="mars_exploration"> <!-- Mars sky and lighting --> <include> <uri>model://mars_sky</uri> </include> <!-- Jezero Crater terrain --> <include> <uri>model://jezero_crater_terrain</uri> <pose>0 0 0 0 0 0</pose> </include> <!-- Add rock samples for collection --> <include> <uri>model://mars_rock_sample</uri> <pose>5 5 0.5 0 0 0</pose> <name>sample_01</name> </include> </world> </sdf>

Step 1: Environment Setup

Configure ROS2 Jazzy/Humble with Gazebo Harmonic

Fall 2025 handout text (not a runnable command)

Start the complete Mars exploration environment

Fall 2025 handout text (not a runnable command)

ros2 launch husky_ur3_mars mars_exploration.launch.py

Step 3: Controllers

Initialize robot controllers and teleoperation

Fall 2025 handout text (not a runnable command)

There is no husky_ur3_simulation package in the repositories linked from these pages.

ros2 launch husky_ur3_simulation controllers.launch.py
ros2 run teleop_twist_keyboard teleop_twist_keyboard

Step 4: Mission Control

Start autonomous navigation and manipulation

Fall 2025 handout text (not a runnable command)

There is no mars_mission package in the repositories linked from these pages.

ros2 launch mars_mission mission_control.launch.py

🔧 Troubleshooting Common Issues

Add command_interface: "velocity" to your controllers.yaml file

Set export LIBGL_ALWAYS_SOFTWARE=1 before launching Gazebo

Increase timeout in launch files: timeout=5.0

🎮 Gripper Control Commands

Fall 2025 handout text

Open Gripper

ros2 topic pub -1 /rh_p12_rn_position/command std_msgs/msg/Float64 '{data: 0.0}'

Close Gripper

ros2 topic pub -1 /rh_p12_rn_position/command std_msgs/msg/Float64 '{data: 1.05}'
