🛠️ Common Debugging Issues

Coding Exercise 1 - Common Errors
❌ Odometry Issues (Post #60):
  • math.radians() on gyro data (already in rad/s!)
  • Using wheel differential for ω instead of gyroscope
  • Updating x,y before theta
  • Wrong dt calculation (use fixed 0.1s)
❌ GPS Issues (Post #61):
  • Adding GPS to odometry (should replace!)
  • Calculating theta from GPS (use gyro only!)
  • Not checking for None values
Assignment 4 - Common Issues
🤖 Robot Won't Move:
  • Missing command_interface: "velocity" in controllers.yaml
  • ROS2 Control not loaded properly
  • Check: ros2 control list_controllers
🖥️ Gazebo Issues:
  • NVIDIA driver conflicts
  • Use LIBGL_ALWAYS_SOFTWARE=1 for VMs
  • Python version mismatches
